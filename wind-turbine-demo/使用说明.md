# WindSight 风力发电机演示版

这是用于演示“节点 → 风机 → 四项工程量”的独立版本。它使用固定上报协议，将每台风机的 4 路 `0..5V` 原始传感器值映射为电压、电流、转速和温度，并在浏览器中显示实时曲线与历史回放。

## 目录

```text
wind-turbine-demo/
├─ server/            Flask + Socket.IO 服务端与风电模拟器
├─ database/          首次启动自动创建 SQLite 数据库
└─ 使用说明.md        本文件
```

## 5 分钟启动

在本目录执行：

```powershell
cd server
py -3.11 -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .\windsight.env.example .\windsight.env
python .\app.py
```

访问 `http://localhost:8080`。

首次启动时：

1. 打开登录页；
2. 若 `windsight.env` 未设置 `WINDSIGHT_DEFAULT_ADMIN_PASSWORD`，服务会生成一次性随机管理员密码并写入 `server\logs\windsight.log`；
3. 建议在 `windsight.env` 中自行设置固定的 `SECRET_KEY` 与管理员密码后再开始演示。

## 演示流程

1. 使用管理员登录；
2. 创建一个节点，例如 `WIND_001`；
3. 在节点详情中复制该节点的 `node_key`；
4. 打开另一个 PowerShell，运行：

```powershell
cd server
.\venv\Scripts\Activate.ps1
python .\sim.py --server http://127.0.0.1:8080 --node-id WIND_001 --sub 4 --node-key "粘贴节点密钥" --interval-ms 1000
```

5. 浏览器打开“实时监测”，选择节点和风机；
6. 打开“历史回放”，查看已保存曲线。

## 风电上报协议

接口：`POST /api/upload`

```json
{
  "node_id": "WIND_001",
  "sub": "4",
  "001": [3.50, 2.00, 2.00, 1.60],
  "002": [3.52, 2.02, 2.03, 1.62],
  "003": [3.54, 2.04, 2.06, 1.64],
  "004": [3.56, 2.06, 2.09, 1.66]
}
```

- `sub`：本帧风机数量，范围 `1..200`；
- 风机编号：三位绝对编号 `001..200`；允许从例如 `031` 开始分包，不要求每包从 `001` 连续开始；
- 每台值顺序：`[电压传感器V, 电流传感器V, 转速传感器V, 温度传感器V]`；所有值范围 `0..5V`。

| 原始通道 | 页面工程量 |
| --- | --- |
| 电压 `0..5V` | `0..250V` |
| 电流 `0..5V` | `0..5A` |
| 转速 `0..5V` | `0..2500 r/min` |
| 温度 `0..5V` | `0..100℃` |

上传默认需要节点认证。模拟器使用 `--node-key` 即可完成教学演示；生产方式可使用界面生成的 HMAC 凭据。

## 运行注意事项

- 本版本适合单机演示：SQLite、在线状态和 Socket.IO 状态均在单进程中；
- 上传间隔应小于设置中的节点离线阈值；
- 数据库、日志和 `windsight.env` 只在本机保留，不应提交到 Git；
- 自检命令：`python -m unittest discover -s tests -v`。
