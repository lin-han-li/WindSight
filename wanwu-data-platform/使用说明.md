# 万物数驱：任意传感器节点数据类型版

这是一个独立的通用数据接入平台。设备、传感器、边缘网关或业务系统可以上报任意 JSON；平台保存完整 JSON、发现其中的数值字段，并以字段名称、语义和单位展示实时与历史曲线。

## 目录

```text
wanwu-data-platform/
├─ server/            Flask + Socket.IO 通用数据服务端
├─ database/          首次启动自动创建 SQLite 数据库
├─ deploy/aliyun/     可选的 Alibaba Cloud Linux 部署模板
└─ 使用说明.md        本文件
```


> 页面操作、节点注册、认证凭据、任意 JSON 示例、实时曲线和排错步骤见 [操作文档.md](./操作文档.md)。

## 5 分钟启动

```powershell
cd server
py -3.11 -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .\windsight.env.example .\windsight.env
# 打开 windsight.env，至少设置 SECRET_KEY；需要 HMAC 时再填写 Fernet 密钥
python .\app.py
```

浏览器访问 `http://localhost:8080`。

建议编辑 `server\windsight.env`：

```ini
SECRET_KEY=请填入固定随机字符串
WINDSIGHT_CREDENTIAL_ENCRYPTION_KEY=请填入固定Fernet密钥
WINDSIGHT_DEFAULT_ADMIN_USERNAME=admin
WINDSIGHT_DEFAULT_ADMIN_PASSWORD=请设置强密码
NODE_TIMEOUT_SECONDS=90
DATABASE_URL=sqlite:///../database/wanwu-shuju.db
```

## 教学演示步骤

1. 以管理员身份登录；
2. 在“我的数据源”注册 `LAB_SENSOR_01`，并复制页面给出的 `node_key`；
3. 保存下列内容为 `payload.json`；
4. 在 PowerShell 中调用上传接口；
5. 打开“实时数据”，选择数据源和字段；
6. 打开“历史回放”，保持同一数据源查看入库记录。

## 任意 JSON 上报

接口：`POST /api/upload`

来源标识可使用以下任意一个字段，优先级依次为 `node_id`、`device_id`、`source_id`。它的值必须与已注册数据源 ID 对应。

```json
{
  "device_id": "LAB_SENSOR_01",
  "telemetry_schema": {
    "environment.temperature": {
      "label": "环境温度",
      "unit": "℃",
      "semantic": "temperature"
    },
    "environment.humidity": {
      "label": "相对湿度",
      "unit": "%RH",
      "semantic": "humidity"
    },
    "power.voltage": {
      "label": "供电电压",
      "unit": "V",
      "semantic": "voltage"
    }
  },
  "environment": {
    "temperature": 24.8,
    "humidity": 56.2
  },
  "power": {
    "voltage": 12.1
  },
  "status": "normal"
}
```

上传示例：

```powershell
curl.exe -X POST "http://localhost:8080/api/upload" `
  -H "Content-Type: application/json" `
  -H "X-WindSight-Node-Key: 粘贴注册时保存的节点密钥" `
  --data-binary "@payload.json"
```

系统会自动得到可绘图字段：

```text
environment.temperature
environment.humidity
power.voltage
```

- 数值：自动进入实时/历史曲线；
- 嵌套对象、数组：递归展开为字段路径；
- 文本、布尔值、`null`：完整保存在原始 JSON 中，但不绘制曲线；
- `telemetry_schema`：由上传端控制显示名称、单位和语义；建议每次上报都带上它，以保持展示稳定。

## 页面说明

- **我的数据源**：注册来源、查看节点密钥/HMAC 凭据；
- **实时数据**：保持原四宫格曲线体验，默认展示已选字段前四项；总通道数不受限制，可通过字段选择切换；
- **历史回放**：按来源、字段、时间范围和记录数查看历史；
- **原始 JSON**：查看当前或历史数据帧完整内容。

## 认证与运行注意事项

- 默认开启上传认证；教学测试可用节点密钥，生产建议 HMAC；
- 使用固定 `SECRET_KEY` 和 `WINDSIGHT_CREDENTIAL_ENCRYPTION_KEY`，避免重启后历史 HMAC 凭据失效；
- SQLite + Socket.IO 当前适合单 worker；
- 自检命令：`python -m unittest discover -s tests -v`；
- Alibaba Cloud Linux 部署参考 `deploy/aliyun/README.md`（服务源码目录是 `server/`）。

## 风机协议兼容说明

为兼容旧设备，本版本仍能接收旧风机帧；新项目开发和教学演示直接使用上方通用 JSON 协议即可。
