# WindSight 原始工程

本分支 `main` 保留原始 WindSight 项目及其原有目录结构。需要使用原有本地路径、模拟器或配套小型服务时，请使用本分支。

分支用途和双项目目录请先阅读 [`分支说明.md`](./分支说明.md)。

常用目录：

- `code/`：原始 WindSight 主应用
- `mini_simulator/`：原有模拟器
- `mini_server/`：配套小型服务
- `mini_one_node/`：单节点示例
- `database/`：本地数据库目录
- `ALiYunFuWuQi/`：服务器连接和部署相关材料

双项目整理分支：[`codex/two-projects-release`](https://github.com/lin-han-li/WindSight/tree/codex/two-projects-release)
